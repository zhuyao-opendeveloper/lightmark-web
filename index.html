    GitHub 仓库同步

    把数据以 lightmark-data.json 的形式存到你的 GitHub 仓库，实现多设备（含 App）互通。Token 仅保存在本机并只发给 api.github.com。

    本地备份 / 与 App 互通

    导出或导入的 JSON 与 Android App 的「备份导出」格式完全一致（SyncData 契约），可直接在 App 内导入。

    关于轻刻网页版
    
        
    轻刻 Android App（v2.0.0 起）是完全离线应用：不声明网络权限、无账号体系。所有在线能力（多端同步、AI 助手）集中在本网页版，二者通过 lightmark-data.json 数据契约互通。
    
        
    数据契约（与 App 一致）
    
        
    {
  "version": 1,
  "lastSync": 1690000000000,
  "todos": [ TodoItem, ... ],
  "categories": [ Category, ... ]
}
    
        
    TodoItem / Category 字段命名与 App 的 SyncData 完全相同（驼峰、color 为数字）。App 导出的备份文件可直接在本页「导入」，反之亦然。
    
        
    托管
    
        
    本页为纯静态站点，可直接放 GitHub Pages / 任意静态托管，无需备案、无后端。
